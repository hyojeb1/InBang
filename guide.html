Unreal — 실행만 하면 무대가 완성된다 ✓ 완료

실행 (별도 Game 프로세스)

# 권장: 저장소 위치와 UE 5.7 설치 경로를 자동 탐색
run-avatar-capture.cmd

# 수동 실행: 작업 PC에 맞게 PROJECT 경로만 선택
set PROJECT=C:\Dev\InBang\InBang\InBang.uproject
# set PROJECT=C:\Dev\00InBang\InBang\InBang.uproject
set CAPTURE_USER_DIR=%LOCALAPPDATA%\InBangAvatarCapture

"C:\Program Files\Epic Games\UE_5.7\Engine\Binaries\Win64\UnrealEditor.exe" ^
  "%PROJECT%" /Game/Lvl_GreenScreen ^
  -game -AvatarCapture -UserDir="%CAPTURE_USER_DIR%" -windowed -ResX=854 -ResY=480 -log

촬영 창 제목은 InBang Avatar Capture. Unreal 뷰포트만 854×480이며 OBS 캔버스·녹화 해상도는 기존 값을 유지한다. -UserDir로 촬영 설정을 일반 게임 설정과 분리하며, 에디터 내부 PIE는 촬영에 사용하지 않는다.

실행하면 자동으로 되는 것 (MyPlayerController C++)

  • 레벨에서 네페르 자동 탐색 (태그 Nefer 우선, 없으면 첫 스켈레탈 캐릭터)
  • CineCamera 자동 생성 — 버스트샷, 50mm, 140cm (레벨에 카메라가 있으면 그걸 사용)
  • 그린스크린 배경 판 자동 생성 — 캐릭터 뒤 3m, #00FF00
  • 자동 눈 깜빡임 시작 — 2~6초 랜덤 간격

방송 중 실시간 튜닝 — 콘솔(~) 명령

명령기능예시
CamDist카메라 거리(cm)CamDist 180
CamHeight시선 높이 (0=발끝, 1=정수리)CamHeight 0.75
CamFocal초점거리(mm)CamFocal 35
ListMorphs모프타겟 전체 목록 출력ListMorphs
Expr모프 하나 직접 실험Expr Eye_Star_L 1.0
Face표정 슬롯 적용Face 3
AutoBlink자동 깜빡임 켜기/끄기AutoBlink false

확정한 값은 Config/DefaultGame.ini의 [/Script/InBang.MyPlayerController]에 적으면 영구 적용 — BP를 열 일이 없다.

OBS 세팅 ← 지금 여기

게임 캡처 (권장)

  • 소스 + → 게임 캡처
  • 모드 → 특정 윈도우 캡처
  • 대상 → InBang Avatar Capture (UnrealEditor.exe)
  • 캡처 프레임레이트 제한 → 켬
  • 커서 캡처 → 끔
  • 서드파티 오버레이 캡처 → 끔
  • 안티치트 호환성 훅 → 끔 (UnrealEditor 촬영에는 불필요)
  • 필터 → 크로마키 → 색상: #00FF00, 유사도 400, 부드러움 80
  • 게임 캡처 레이어 위에 오버레이로 배치
  • 키잉 품질이 아쉬우면: 에디터에서 언릿 초록 머티리얼을 /Game/M_GreenScreen으로 만들기만 하면 자동 사용됨

대체 순서: 게임 캡처가 실패할 때만 윈도우 캡처를 사용한다. 디스플레이 캡처는 진단용 또는 최후 수단이다. DX12 게임 캡처만 계속 실패하면 run-avatar-capture.cmd -dx11로 한 번 진단하되 기본 실행 옵션으로 저장하지 않는다.

  트랙 2: 마이크만   (whisper.cpp 전용 — 방송엔 안 나감)

  • 권장 비트레이트: 6000~8000 Kbps

whisper.cpp — 하이라이트 인덱싱 파이프라인

설치

git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp
make # CUDA 있으면: make WHISPER_CUBLAS=1
bash ./models/download-ggml-model.sh large-v3

방송 후 처리 스크립트

#!/bin/bash
# process.sh <녹화파일.mkv>
INPUT="$1"
STEM="${INPUT%.*}"

# 마이크 트랙(2번)만 추출
ffmpeg -i "$INPUT" -map 0:a:1 -ar 16000 -ac 1 "${STEM}_mic.wav"

# 한국어 변환 + 타임스탬프
./whisper.cpp/main \
  -m ./whisper.cpp/models/ggml-large-v3.bin \
  -l ko \
  -f "${STEM}_mic.wav" \
  --output-srt \
  --output-txt

echo "완료: ${STEM}_mic.wav.srt"

하이라이트 찾는 법

  • .srt 파일에서 재밌는 대사 타임스탬프 확인
  • 해당 구간 ±30초 영상 컷
  • 유튜브 쇼츠 or 일반 영상으로 업로드

로드맵 — 첫 방송 이후

립싱크 (난이도 ★★)

  • 메시에 Mouth_A/I/U/E/O가 이미 있음 → 마이크 볼륨 기반 입 벌림부터 시작
  • UE AudioCapture로 마이크 진폭 측정 → Mouth_A 가중치에 매핑 (C++ 반나절)
  • 고급: 포먼트 분석으로 A/I/U/E/O 구분

얼굴 트래킹 — Live Link Face (난이도 ★★★)

  • 아이폰 Live Link Face 앱 → UE 기본 지원, 고개·표정이 실시간으로 따라옴
  • 단, ARKit 블렌드셰이프 52개 네이밍이 필요 → 아트팀에 리네이밍/추가 작업 요청 필요
  • 현재 모프 35개와 상당수 겹치므로 매핑 테이블로 부분 대응도 가능

치지직 연동 (난이도 ★★)

  • 치지직 채팅 API → 후원/구독 시 표정 자동 반응 (Face(3) 호출)
  • 채팅 오버레이는 OBS 브라우저 소스로 처리하는 게 간단

잔여 정리 (5분)

  • 에디터에서 Lvl_GreenScreen World Settings → GameMode Override를 None으로 (삭제된 BP_MyGameMode 참조 경고 제거 — 동작엔 지장 없음)
  • 정리 커밋: LeDuat UI·템플릿 콘텐츠 삭제분 + 방송 C++ 반영
