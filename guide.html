Unreal — 그린스크린 레벨 세팅

카메라 배치

  • CineCamera Actor 배치 → 버스트/가슴 앵글 고정
  • Auto Activate 켜기 → 게임 시작 시 자동 전환
  • Field of View: 35~50mm 권장 (버튜버 느낌)
  • Lock to HMD: Off

그린스크린 머티리얼 확인

  • 배경 전체 M_GreenScreen 또는 단색 #00FF00 적용 확인
  • 캐릭터에 그린이 묻지 않게 조명 방향 주의
  • ToonShade 머티리얼 적용 시 외곽선 색상 확인

실행 설정

# 에디터 없이 창모드로 실행 (OBS 캡처용)
UnrealEditor.exe InBang.uproject -game -windowed -ResX=1920 -ResY=1080

또는 에디터에서 Play → Standalone Game

표정 전환 — Huion Key-Dial + Blueprint

Huion Key-Dial 매핑

Huion 소프트웨어에서 버튼 두 개를 키보드 키로 지정

버튼 1  →  키보드 F1  (기본 표정 / Neutral)
버튼 2  →  키보드 F2  (반응 표정 / Alt)

Enhanced Input 설정

  • Content/Input/IMC_Default.uasset 열기
  • Input Action 추가: IA_Expr_Neutral, IA_Expr_Alt
  • 각각 F1, F2 키 바인딩
  • Trigger: Pressed

Level Blueprint — 표정 전환 로직

// IA_Expr_Neutral Triggered
Get Skeletal Mesh Component (네페르)
  → Set Morph Target ("expr_neutral", 1.0)
  → Set Morph Target ("expr_alt", 0.0)

// IA_Expr_Alt Triggered
Get Skeletal Mesh Component (네페르)
  → Set Morph Target ("expr_neutral", 0.0)
  → Set Morph Target ("expr_alt", 1.0)

아트팀 허락 전: 임시 메시 + 임의 모프타겟 이름으로 파이프라인만 테스트

OBS 세팅

소스 구성

  • 창 캡처 → Unreal Standalone 창 선택
  • 필터 → 크로마키 → 색상: #00FF00, 유사도 400, 부드러움 80
  • 게임 캡처 레이어 위에 오버레이로 배치

오디오 트랙 분리 (핵심)

설정 → 출력 → 녹화 → 오디오 트랙
  트랙 1: 전체 믹스  (스트림 + 녹화)
  트랙 2: 마이크만   (whisper.cpp 전용 — 방송엔 안 나감)

치지직 RTMP 설정

  • 설정 → 방송 → 서비스: 사용자 지정
  • 서버: rtmp://rtmp-push.chzzk.naver.com/live
  • 스트림 키: 치지직 대시보드에서 발급
  • 권장 비트레이트: 6000~8000 Kbps

whisper.cpp — 하이라이트 인덱싱 파이프라인

설치

git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp
make # CUDA 있으면: make WHISPER_CUBLAS=1
bash ./models/download-ggml-model.sh large-v3

방송 후 처리 스크립트

#!/bin/bash
# process.sh <녹화파일.mkv>
INPUT="$1"
STEM="${INPUT%.*}"

# 마이크 트랙(2번)만 추출
ffmpeg -i "$INPUT" -map 0:a:1 -ar 16000 -ac 1 "${STEM}_mic.wav"

# 한국어 변환 + 타임스탬프
./whisper.cpp/main \
  -m ./whisper.cpp/models/ggml-large-v3.bin \
  -l ko \
  -f "${STEM}_mic.wav" \
  --output-srt \
  --output-txt

echo "완료: ${STEM}_mic.wav.srt"

하이라이트 찾는 법

  • .srt 파일에서 재밌는 대사 타임스탬프 확인
  • 해당 구간 ±30초 영상 컷
  • 유튜브 쇼츠 or 일반 영상으로 업로드
